# 辰CHEN 平台應用程式開發指令集

本文檔整理了辰CHEN平台的前台模組、遊戲邏輯、資料結構與後台需求，作為開發指引。

## 前台頁面模組
### 乾盤（公開抽獎）
- 平台官方抽獎盤，24 小時無抽取自動下架換新。
- 展示大獎、一般賞、最後賞及 1/5/10 抽價格按鈕。
- 單一玩家抽取時其他人排隊，避免尾刀；抽獎過程即時更新剩餘籤數。
- 跑馬燈公告中獎資訊（「XX 玩家在第 YY 號籤抽中 ZZ 獎」）。

### 坤盤（私人客製抽獎）
- 玩家花費 1 星辰開盤，自選大獎與籤筒總數；價格使用 H 曲線公式並不可低於系統最低價。
- 可設定公開/私有。預設房間命名：開盤者 ID + 五行元素（木、火、土、金、水），最多同時 5 盤。
- 7 天無人抽取或大獎抽出即結束並 2 小時後封存。
- 他人參與時每累計 5 個無情小賞產生 1 點坤星辰；累積 10 點坤星辰獎勵開盤者 1 星辰。實時更新累積提示。
- 使用「法器」時播放特效，該盤不可累積星辰。

### 辰境（辰爆活動盤）
- 平時顯示龍紋靈脈進度條，僅辰爆事件開放。
- 入場需 5 星辰，每抽 1 星辰（至少 6 星辰可參與）；提供 1/5/10 抽按鈕。
- 大獎抽出即結束；開啟時入口高亮並跑馬燈公告，活動後彈出個人獲獎與星辰消耗總覽。

### 星辰商店（驛站）
- 列出可用星辰兌換的商品：名稱、圖片、所需星辰。
- 點擊兌換扣除星辰生成訂單；可在未出貨獎品列表選擇「兌換星辰」賣回平台（依回收價）。
- 即時更新星辰餘額與交易結果。

### 會員資訊頁面
- 顯示暱稱、ID、聯絡方式、是否綁定 Line、點數與星辰餘額及「購買點數」入口。
- 顯示 VIP 等級與勳章入口（預留）。
- 記錄分頁：購買點數、消費、星辰煉化、驛站兌換；未出貨獎品提醒 7 日內申請出貨。
- 獎池櫃展示歷史大獎縮圖（懸浮顯示時間與來源）；背包列出未用道具。

### 登入/註冊與首頁框架
- 首頁含 LOGO、導航（乾盤、坤盤、辰境、商店、會員中心等）、廣告橫幅、跑馬燈公告、精選熱盤。
- 未登入顯示登入/註冊並支援第三方（Line）。登入後展示用戶資訊摘要。
- 顯示辰爆進度或倒數，框架需響應式且為各模組路由提供基礎。

## 遊戲邏輯系統
### 星辰與靈脈計算
- 星辰為玩家貨幣，乾盤每 10 個一般賞煉化 1 星辰，坤盤每 5 個煉化 1 點坤星辰（同質星辰）。
- 星辰用途：開坤盤、辰境入場與抽取、星辰商店兌換；可用點數購買或賣出實物獲取。
- 靈脈 PR 值：每日利潤優先填滿安全池（2.5 倍大獎成本總和）。超出部分 30% 轉為 PR 值。
- 辰爆觸發：PR 值達門檻（預設 15 萬）且 7 天不下降觸發辰爆，PR 歸零。可分配部分 PR 至特斯拉終極獎池。

### 坤盤抽價公式（H 曲線）
- 最低單抽價 = 獎品成本 / (成本值 0.33 × TU 係數)，抽數越多 TU 越低，單價遞減。
- 價格進位至 5 或 0 結尾，單抽不得低於 50 元；提供單抽、5 連抽（加價後 ×5）、10 連抽價格。
- 高 VIP 可解鎖更高抽數檔次。

### 辰爆與封印石
- 辰爆開放辰境；辰境獎池含封印石等稀有獎品。
- VIP3（玄武）以上可查看特斯拉獎池 PR 進度。
- 特斯拉專屬 PR 達 300 萬觸發封印石解封：隨機選出一枚封印石獲得終極獎，其餘保留下次。

### 共命盤組隊玩法
- 乾共命盤：玩家選官方獎池開房，預設人數/抽數檔，加入即付費；人數升檔退差價。滿員或截止開抽，按順序輪抽，大獎出即結束；48 小時未滿員取消並退費。可選自動代抽與提醒。
- 坤共命盤（預留）：玩家自選獎品，總抽數 = 人數 × 6，採 35% 利潤率公式定價，勝者全拿，大逃殺模式淘汰，無個人小賞星辰。

### 大逃殺動畫邏輯
- 以籤筒展示參與者，閃爍洗牌後逐一翻轉淘汰，淘汰籤筒淡出，直至剩最後一人高亮為勝者；前端動畫與音效演繹，結果以後端隨機為準。

## 資料結構
### 會員等級 (VIP Levels)
- VIP0～VIP5（凡君、青木、赤炎、玄武、天辰、太乙），依累計星辰兌換量升級（10/100/500/2000/9999）。
- 權益：更高抽數、查看封印石 PR（VIP3+）、坤盤自訂賞位（VIP4+）等；結構需存權限標記。

### 抽獎盤資訊 (LotteryBoard)
- 欄位：盤 ID、類型、名稱、開盤者、時間、總/剩餘籤數、單抽與優惠價、公開狀態、法器標記、共命盤人數與代抽設定等。
- 獎項列表包含 ID、名稱、類別、大獎/一般賞/最後賞、數量、圖片、兌換價值；狀態標識 active/pending/completed/archived。
- 可含累計星辰統計等分析欄位。

### 星辰流向記錄 (StarTransaction Log)
- 記錄 ID、時間、會員 ID、變動類型（獲得/消耗與來源）、數量；來源/用途例：煉化、獎品回收、開盤、辰境入場/抽取、商城兌換、交易購買/賣出等。
- 外鍵關聯會員與盤/商品，支援查詢與統計。

### 抽中記錄 (DrawLog)
- 每次抽籤的盤 ID、序號、時間、抽取者、結果（類別、名稱、是否觸發星辰轉換）、以及星辰交易關聯。
- 記錄大獎抽出以更新盤狀態；共命盤需房間 ID、勝者記錄等，支援高併發寫入與查詢。

## 後台管理需求
### 平台風控中心
- 顯示營收/支出/淨利潤、安全池填充率、PR 值進度，PR 逼近觸發門檻時警示。
- 監控各盤利潤率，低於閾值提醒；提供日期、類型篩選與報表導出。

### 商品點數定價表
- 點數儲值檔：金額、點數量、贈點比例，可增刪調整。
- 星辰兌換定價：依商品成本區間配置星辰價格與回收價，前端兌換與回收依此計算。

### VIP 權限管理
- 配置升級條件與權益（最大坤盤抽數、自訂賞位、查看封印石 PR 等）。
- 支援手動調整玩家 VIP 等級，查看各級人數名單。

### 封印石配對
- 管理封印石發放、持有人與特斯拉 PR 進度。
- PR 達標時啟動隨機抽取，標記中獎封印石並通知前端；保留未中獎封印石。
- 支援手動發放/收回與配置轉入特斯拉獎池比例，並保存審計日誌。
